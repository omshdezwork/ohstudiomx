# Guía de imágenes para Oh Studio

Usa esta guía para crear imágenes con ChatGPT y reemplazarlas después en la carpeta `assets/images/` o `assets/mockups/`.

## 1. Portada / Inicio

**Tipo de imagen:** imagen panorámica completa para hero, con onda blanca inferior integrada.

**Qué debe mostrar:** fondo morado premium, mockup de celular o piezas de marca Oh Studio del lado derecho, espacio libre del lado izquierdo para colocar texto, y una onda blanca suave en la parte inferior.

**Formato recomendado:** PNG o JPG horizontal.

**Tamaño sugerido:** 1536 x 1024 px, 1920 x 1080 px o 1920 x 1200 px.

**Prompt sugerido:**  
Imagen hero panorámica para landing page de Oh Studio, fondo morado premium, objetos 3D de branding y celular del lado derecho, espacio libre oscuro del lado izquierdo para texto, logo Oh Studio en mockups, onda blanca suave en la parte inferior de izquierda a derecha, estilo elegante, limpio y profesional.

## 2. Servicios

**Tipo de imagen:** iconos simples o mini ilustraciones.

**Qué debe mostrar:** seis iconos coherentes para identidad, espacios, impresión, instalación, redes sociales y asesoría.

**Formato recomendado:** SVG o PNG con fondo transparente.

**Tamaño sugerido:** 256 x 256 px por icono.

**Prompt sugerido:**  
Set de seis iconos minimalistas para estudio creativo, líneas blancas y moradas, estilo moderno, identidad visual, ambientación de espacios, impresión, instalación, redes sociales y asesoría, fondo transparente.

## 3. Transformación visual

**Tipo de imagen:** composición antes/después o escritorio creativo.

**Qué debe mostrar:** una idea desordenada transformándose en una propuesta clara: bocetos, paleta de color, logo, material impreso, mockups.

**Formato recomendado:** PNG horizontal con fondo transparente o fondo lila claro.

**Tamaño sugerido:** 1200 x 800 px.

**Prompt sugerido:**  
Ilustración premium de transformación visual, de bocetos e ideas sueltas hacia una identidad profesional, paleta morada, tarjetas, laptop, muestras de color, estilo limpio y elegante para landing page.

## 4. Proyectos / Galería

**Tipo de imagen:** fotos o renders de proyectos terminados.

**Qué debe mostrar:** resultados visuales bonitos y profesionales: negocios, espacios, letreros, impresos, redes sociales, branding aplicado.

**Formato recomendado:** JPG o PNG.

**Tamaño sugerido:** 900 x 1200 px para cada imagen.

**Prompt sugerido:**  
Render fotorealista de proyecto visual terminado por un estudio creativo, negocio pequeño transformado con branding morado elegante, letrero, materiales impresos, decoración limpia, estilo premium, iluminación suave.

## 5. Ecosistema visual

**Tipo de imagen:** mockup de varios soportes trabajando juntos.

**Qué debe mostrar:** laptop, celular, tarjetas, vaso, letrero, señalética, redes sociales y materiales impresos con una misma identidad visual.

**Formato recomendado:** PNG horizontal con fondo transparente.

**Tamaño sugerido:** 1400 x 900 px.

**Prompt sugerido:**  
Mockup de ecosistema visual para Oh Studio, laptop con página web, celular con Instagram, tarjetas de presentación, vaso, letrero, señalética e impresos, todos con identidad morada elegante, fondo transparente, estilo premium.

## 6. Paquetes

**Tipo de imagen:** no es indispensable.

**Qué debe mostrar si decides usar imagen:** pequeñas etiquetas, tarjetas de precio o elementos de papelería. Esta sección funciona mejor con diseño gráfico limpio y sin fotos grandes.

**Formato recomendado:** SVG o PNG pequeño.

**Tamaño sugerido:** 600 x 400 px.

**Prompt sugerido:**  
Ilustración minimalista de paquetes de diseño creativo, tres tarjetas premium con acentos morados, iconos simples, estilo limpio para landing page.

## 7. Proceso

**Tipo de imagen:** iconos de pasos o línea de proceso.

**Qué debe mostrar:** escuchar, diseñar, planear, implementar y entregar.

**Formato recomendado:** SVG o PNG transparente.

**Tamaño sugerido:** 256 x 256 px por paso.

**Prompt sugerido:**  
Set de cinco iconos minimalistas para proceso creativo: escuchar, diseñar, planear, implementar y entregar, estilo línea, tonos morados, fondo transparente.

## 8. Quiénes somos / Contacto

**Tipo de imagen:** retrato de estudio o composición de marca.

**Qué debe mostrar:** escritorio creativo, libreta, laptop, muestras de color, materiales Oh Studio, ambiente cercano y profesional.

**Formato recomendado:** JPG horizontal o PNG.

**Tamaño sugerido:** 1200 x 800 px.

**Prompt sugerido:**  
Fotografía editorial de escritorio de estudio creativo, libreta con bocetos, laptop, muestras de color morado, tarjetas de marca Oh Studio, ambiente cálido, profesional, elegante, sin personas visibles.

## Recomendación general

Mantén todas las imágenes con:

- Morados profundos y lilas.
- Fondo limpio.
- Luz suave.
- Pocos elementos.
- Estética premium, no saturada.
- Sin colores fuertes ajenos a la marca.
